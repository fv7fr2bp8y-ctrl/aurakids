# Ударения за гласа

`stress-bg.tsv.gz`: форма на дума → индекс на ударената буква (дума<TAB>индекс),
само форми с **едно** ударение. 158 079 форми.

- Източник: Уикиречник (Wiktionary), българските думи, в машинен вид от
  kaikki.org (https://kaikki.org/dictionary/Bulgarian/), файл от 30.10.2026.
- Лиценз на данните: CC BY-SA 4.0 (Wiktionary contributors). Производният
  файл тук е под същия лиценз.
- Построен с `build_stress.py`: python3 build_stress.py <kaikki.jsonl> stress-bg.tsv.gz
- Двусмислени форми (хо́рата/хора́та, ска́лата/скала́та) и думи с една гласна
  не са включени: там гласът чете сам.

Ред на предимство в `src/lib/stress.ts`: проверени думи за приказката
(rechnik.chitanka.info) → общият речник на ONIRA → този речник.
